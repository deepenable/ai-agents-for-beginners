# AI 智能体课程学习路线

## 学习目标

本课程面向能阅读 Python、理解函数和基本 HTTP 请求，希望把大语言模型接入工具、知识和业务流程的开发者。完成课程后，你应能解释智能体何时适用，运行并调整旅行助手、客服和工作流示例，使用明确的评估标准检查行为，并识别部署、费用、权限与安全边界。

本手册覆盖原课程 **00 环境准备及 01–18 全部正式模块**。学习主线是 Python；原有 .NET、替代模型和进阶示例作为相应模块的补充路线保留，不要求每个学习者同时搭建所有环境。课程不是一个自动部署包：平台只展示正文和图片，不会执行代码、安装依赖或替你创建云资源。

## 准备条件与费用边界

- 主线目标环境：Windows 11、PowerShell 7、Python 3.12 或更高版本、Git，以及支持 Python/Jupyter 的编辑器。按环境准备章节选择解释器；不把本次内容整理机器的版本当作教学演练版本。
- 多数模型实验需自备 Azure 订阅、可访问的 Microsoft Foundry 项目或 Azure OpenAI 资源、兼容模型部署及足够配额。部分例子另需 Search、Bing、浏览器依赖或外部模型服务，具体要求写在各实践章节。
- 17 的本地路线需要设备资源、模型下载和 Foundry Local；18 的回执练习可先做纯本地验证，不需要云模型调用。
- **云模型调用、搜索、部署、存储、网络和 Codespaces 都可能收费。没有预算和资源所有者批准时，只做源码阅读与本地不联网练习，不执行云端单元格。**
- 本次交付不要求平台分发账号、凭据或 GitHub Copilot 席位。自备账号不等于平台资源包；手册中的占位符也不会被平台自动替换。

## 学习路线

先完成环境准备，再按平台实验顺序学习。01–05 建立智能体、框架、设计原则、工具使用和检索增强的基础；06–10 处理信任、规划、多智能体、反思和生产质量；11–14 连接协议、上下文、记忆与框架工作流；15–18 面向浏览器操作、规模化、本地运行和可验证安全。

每个正式主题分为“概念”和“实践”：先用具体问题推演设计，再进入真实源代码。概念活动不是云端执行的替代凭证；没有跑过实践就不能记录为实验通过。仅当某路线标明可选，才可以在该路线不具备资源时先完成主线并记录未完成项。

## 操作步骤

1. 阅读[环境准备](00-setup.zh-CN.md)，取得固定版本的课程源码，在独立虚拟环境安装依赖。
2. 用一张本地学习记录表，为每个模块写下：任务输入、允许使用的工具、成功条件、执行环境、实际结果和清理状态。记录不含账号、订阅 ID、端点、密钥或完整日志。
3. 每次打开 notebook，先阅读所有 Markdown 和代码单元格，再从头按顺序运行；不要先点“全部运行”，以免触发未审查的网络调用或写入。
4. 对包含随机模型输出的步骤记录行为证据，例如工具被正确调用、约束未违反、检索证据支持结论，而非要求文本逐字匹配手册示例。
5. 在每个模块结束时执行该章清理步骤，把“完成”“失败”“未执行”分开记录。遇到失败，保留去敏后的错误类别和失败单元格，不提交原始环境文件。
